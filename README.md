# Lasco Store

Flutter e-commerce app for multi-platform store management.

## Features
- Product catalog and management
- Shopping cart and checkout
- Brand and category browsing
- Order tracking
- User profiles

## Tech Stack
- Flutter and Dart
- REST API
- State management (Bloc/Cubit)
- Cross-platform (Android, iOS, Web)

## Getting Started

```bash
flutter pub get
flutter run
```
